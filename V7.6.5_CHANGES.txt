FocusLock V7.6.5

Fixes:
1. Settings typing protection:
   - Still requires manually typing the complete challenge.
   - Paste remains blocked.
   - Matching is now case-insensitive.
   - Unicode is normalized.
   - CR/LF and repeated whitespace are normalized.
   - Full content, punctuation and 6-character confirmation token are still required.

2. Add App / Website:
   - These operations are intentionally blocked while Settings Protection,
     Strict Mode, Locked Session or Focus-only is active.
   - The UI now shows the Guard rejection in a visible MessageBox instead of
     making the user hunt for a footer message.
   - The Settings Protection error now correctly points to the Settings page.

3. Browser timing core from V7.6.4 is untouched.
4. publish\Data is untouched.
