FocusLock V7.0 — Website Focus 2.0 + Per-App Lock + Block Profiles

1. Website Focus 2.0
- Browser content script reports trusted click/keyboard/scroll/touch activity.
- Active-tab video/audio progress can qualify as Focus while the browser is foreground.
- Background/minimized/hidden tabs do not earn Focus.
- UI shows whether the current learning website is actually earning Focus.

2. Per-app entertainment lock mode
- Đóng ứng dụng: force-close when locked.
- Khóa tại chỗ: suspend the process so it stays open but cannot be used; resume automatically when unlocked.
- Chặn mở lại: any matching launch while locked is immediately blocked/closed.

3. Block Profiles
- Create groups such as Game, Social, Video.
- Assign an entertainment app to a profile by clicking its profile button.
- Enable/disable a profile as a group.

4. Preserved fixes
- V6.6 Auto Guard reconnect/start.
- V6.7 Named Pipe ACL/runtime fix.
- V6.8 publish\Data ACL fix for LocalSystem and guard.secret.
- Existing publish\Data is preserved by the normal build/update flow.
